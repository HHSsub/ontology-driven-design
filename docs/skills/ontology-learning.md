# ontology-learning

클로드의 영구적 온톨로지 진화를 강제합니다.

슬래시 커맨드: `/ontology-learning`

실수가 발생했을 때 단순 수정(패칭)이 아닌 그 실수를 만들어낸 사고 레이어를 역추적해 L0~L3 전체를 재설계한다. Phase 1(현상 포착) → Phase 2(판단 역추적) → Phase 3(구조 부재 진단) → Phase 3.5(조건부 detach: 반복 실수 또는 개념 부재 시 ontology-detach 발동) → Phase 4(세계관 추출) → Phase 5(메모리 저장) → Phase 6(훅 평가) 순으로 강제 실행된다. Phase 5 생략 시 실행 실패로 간주한다.

자세한 내용은 [스킬 파일](https://github.com/HHSsub/ontology-driven-design/blob/main/skills/ontology-learning/SKILL.md)을 참고하세요.
