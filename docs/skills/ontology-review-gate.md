# ontology-review-gate

구현 전 L0 연결을 검증하는 게이트입니다.

슬래시 커맨드: `/ontology-review-gate`

상체(L0~L1)가 하체(L2~L3) 실행을 살려야 한다. 이 게이트는 실행을 막는 장벽이 아니라, 방향 없는 실행이 낭비가 되는 것을 막는 명확성 검증이다. PASS를 받은 이후 구현을 시작한다.

자세한 내용은 [스킬 파일](https://github.com/HHSsub/ontology-driven-design/blob/main/skills/ontology-review-gate/SKILL.md)을 참고하세요.
