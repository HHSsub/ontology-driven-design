# ontology-learning

Forces Claude's permanent ontological evolution.

Slash command: `/ontology-learning`

When a mistake occurs, instead of patching the symptom, this skill traces back through the reasoning layers that caused it — redesigning L0~L3 entirely. Executes in sequence: Phase 1 (capture phenomenon) → Phase 2 (trace judgment failure) → Phase 3 (diagnose structural absence) → Phase 3.5 (conditional detach: invoke ontology-detach if repeated mistake or unknown concept) → Phase 4 (extract worldview principle) → Phase 5 (write memory) → Phase 6 (evaluate hooks). Skipping Phase 5 is considered execution failure.

See [skill file](https://github.com/HHSsub/ontology-driven-design/blob/main/skills/ontology-learning/SKILL.md) for full details.
