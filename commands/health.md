# /health — 시스템 건강 상태 점검

L0: 현재 시스템이 L0를 달성할 수 있는 상태인지 확인 — 결함을 모르면 고칠 수 없다

이 커맨드는 `health` 스킬을 발동한다.

## 즉시 수행할 것

`Skill` 도구로 `health` 스킬을 invoke하라.

## 점검 항목 (스킬이 결정)

- 의존성 설치 상태
- 환경변수/설정 파일 존재 여부
- 서비스 프로세스 활성 여부
- 최근 에러 로그
- 미완성 파이프라인 단계 (terminal 상태에서 멈춘 것)

## 관련 커맨드

- `/pyramid-topology` — 코드 레벨 L0-L3 위계 점검
- `/debug` — 발견된 문제 근본 원인 추적
