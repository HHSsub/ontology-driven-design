# /investigate — 심층 조사

L0: 정보 수집 전 L0 역도출 — 키워드 기반 랜덤 검색은 L3 자동실행이다

이 커맨드는 `investigate` 스킬을 발동한다.

## 즉시 수행할 것

`Skill` 도구로 `investigate` 스킬을 invoke하라.

## 조사 원칙

1. **L0 역도출 먼저** — "무엇을 알아야 이 판단을 내릴 수 있는가?"
2. **필요 데이터 유형 정의** — 숫자/패턴/사례/스펙 중 무엇이 필요한가?
3. **최적 단일 소스 식별** — 공식 페이지, 전문 DB, 검증된 레지스트리 순
4. **검증 상태 명시** — 모든 정보는 `확인됨:` 또는 `미확인:` 표기 후 사용

키워드 기반 랜덤 검색 → 즉시 STOP. L0 먼저.

## 관련 커맨드

- `/pyramid-ontology` — 조사 목적의 L0 선언
- `/ontology-learning` — 잘못된 조사 패턴 발견 시 온톨로지 진화
