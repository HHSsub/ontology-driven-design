# /review — 코드·문서 온톨로지 리뷰

L0: 산출물이 L0를 달성하는 구조인지 독립적으로 검토 — 만든 사람이 보지 못하는 것을 본다

이 커맨드는 `review` 스킬을 발동한다.

## 즉시 수행할 것

`Skill` 도구로 `review` 스킬을 invoke하라.

## 리뷰 기준 (스킬이 강제)

1. **L0 연결** — 모든 파일/모듈/섹션이 L0 달성에 기여하는가?
2. **탈존재(ontology-detach)** — 특정 플랫폼/서비스/도구에 교체조건 없이 묶인 binding 있는가?
3. **SSOT** — 열거형 개념 모음이 여러 곳에 복제·분기되어 있는가?
4. **완료 기준** — 파이프라인이 L0 달성 전에 terminal 상태로 끝나는 경로 있는가?

## 관련 커맨드

- `/ontology-review-gate` — 구현 전 온톨로지 법정 검토 (blocking)
- `/ontology-learning` — 리뷰에서 발견한 패턴 실수 온톨로지 진화
- `/pyramid-topology` — 전체 위계 구조 스캔
