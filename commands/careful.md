# /careful — 비가역 행동 안전 게이트

L0: 되돌릴 수 없는 행동은 실행 전 L0 연결을 반드시 확인한다

이 커맨드는 `careful` 스킬을 발동한다.

## 즉시 수행할 것

`Skill` 도구로 `careful` 스킬을 invoke하라.

## 비가역 행동 목록 (이 커맨드 발동 대상)

- 파일/디렉토리 삭제
- DB 데이터 변경·삭제
- 배포 (프로덕션 push, 서비스 재시작)
- 외부 API 호출 (이메일 발송, 결제, 알림)
- git force push, reset --hard
- 환경변수·시크릿 변경

## 확인 절차 (스킬이 강제)

1. "이 행동이 어떤 L0를 달성하는가?" → 답 없으면 실행 금지
2. "L0 미달 상태 항목에 영향을 주는가?" → 예이면 실행 금지
3. "되돌릴 수 없는가?" → 예이면 실행 방법과 영향 범위 먼저 사용자에게 보고

## 관련 커맨드

- `/pyramid-ontology` — L0 연결 선언
- `/ontology-learning` — 비가역 행동 실수 발생 시 온톨로지 진화
