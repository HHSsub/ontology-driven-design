# /debug — 체계적 디버깅

L0: 증상 억제가 아닌 근본 원인 제거 — 같은 버그가 다른 형태로 재발하지 않게

이 커맨드는 Superpowers systematic-debugging 스킬을 발동한다.

## 즉시 수행할 것

`Skill` 도구로 `superpowers:systematic-debugging` 스킬을 invoke하라.

## 디버깅 원칙 (스킬이 강제)

1. **현상 기록** — 재현 조건, 실제 vs 기대 출력, 에러 메시지 전문
2. **가설 생성** — L3 증상에서 L2 판단 실패, L1 구조 결함, L0 단절까지 역추적
3. **최소 재현** — 범위를 좁혀 원인을 고립
4. **수정 + 검증** — 수정 후 반드시 실행해서 실제 출력 첨부

추측으로 수정 시작 금지. 가설 먼저.

## 관련 커맨드

- `/ontology-learning` — 디버깅 과정에서 발견한 판단 패턴 실수를 온톨로지 진화로
- `/tdd` — 버그 수정 후 회귀 방지 테스트 작성
