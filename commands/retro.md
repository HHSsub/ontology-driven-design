# /retro — 세션 회고 + 온톨로지 진화

L0: 실수에서 실제로 배우는 것 — "다음엔 조심" = 진화 아님, 메모리 저장 없으면 다음 세션 같은 실수

이 커맨드는 세션 회고를 실행하고 온톨로지 진화를 유도한다.

## 즉시 수행할 것

`Skill` 도구로 `ontology-learning` 스킬을 invoke하라.

## 회고 프로세스

이 세션에서 발생한 실수·수정·방향 전환을 모두 역추적한다:

1. **Phase 1 — 현상 포착 (L3)**: 이 세션에서 무엇이 잘못됐나?
2. **Phase 2 — 판단 역추적 (L2)**: 어떤 가정/결정이 그 현상을 만들었나?
3. **Phase 3 — 구조 부재 진단 (L1)**: 어떤 체크포인트가 없었나?
4. **Phase 4 — 세계관 추출 (L0)**: 이 실수의 뿌리에 있는 잘못된 원칙은?
5. **Phase 5 — 메모리 저장**: `feedback_ontology_*.md` 파일 생성 + `MEMORY.md` 포인터 추가

메모리 저장 없이 완료 = 이 커맨드 미실행.

## 관련 커맨드

- `/ontology-learning` — 세션 중 실수 즉시 처리 (retro는 세션 종료 시)
- `/pyramid-ontology` — 다음 세션 L0 선언
