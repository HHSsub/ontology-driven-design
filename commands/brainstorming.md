# /brainstorming — 아이디어를 설계로 변환

L0: 구현 전 설계 합의 — 가정 없이 만들기 시작하면 반드시 다시 만든다

이 커맨드는 Superpowers brainstorming 스킬을 발동한다.

## 즉시 수행할 것

`Skill` 도구로 `superpowers:brainstorming` 스킬을 invoke하라.

스킬 발동 전 구현·코드 작성·파일 생성 절대 금지.

## 프로세스 (스킬이 강제)

1. 프로젝트 컨텍스트 탐색 (파일, 최근 커밋, 문서)
2. 명확화 질문 — 한 번에 하나씩
3. 2-3가지 접근법 제안 + 트레이드오프
4. 설계 섹션별 제시 + 사용자 승인
5. 설계 문서 저장 (`docs/superpowers/specs/YYYY-MM-DD-<topic>-design.md`)
6. writing-plans 스킬로 전환 (구현 계획 작성)

## 관련 커맨드

- `/plan` — 설계 완료 후 구현 계획 작성
- `/pyramid-ontology` — 설계 전 L0 선언 강제
- `/ontology-review-gate` — 설계 후 온톨로지 법정 검토
